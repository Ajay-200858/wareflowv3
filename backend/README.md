# WareFlow Backend

This is the FastAPI backend for the WareFlow system. It uses MySQL for persistence, SQLAlchemy for ORM, and integrates simple ML scripts for demand forecasting and assignments.

## Requirements
- Python 3.9+
- MySQL 8.x

## Setup

1. **Install Dependencies**
   ```powershell
   python -m venv venv
   .\venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. **Database Configuration**
   - Ensure MySQL 8.x is running on your machine (e.g. via Windows Services `Start-Service MYSQL80`).
   - Copy `.env.example` to `.env` and adjust the credentials. By default, it looks for:
     `mysql+pymysql://root:password@localhost:3306/wareflow`
   - Log into MySQL and create the database:
     ```sql
     CREATE DATABASE wareflow;
     ```

3. **Run Migrations**
   - We use Alembic to manage database schema changes.
   - Run the initial migration to create all tables:
     ```powershell
     alembic revision --autogenerate -m "Initial schema"
     alembic upgrade head
     ```

4. **Seed the Database**
   - The system needs initial users, a company, and warehouse locations.
   - Run the seeder script which creates the structure and mock sales history:
     ```powershell
     python scripts/seed_demo.py
     ```
   - *Test credentials:*
     - Admin: `admin@wareflow.demo` / `password123`
     - Manager: `manager@wareflow.demo` / `password123`
     - Employee: `employee@wareflow.demo` / `password123`

5. **Train ML Models (Optional)**
   - To power the AI decisions, run the synthetic ML training script. It trains a RandomForestRegressor on the mock sales data generated by the seeder.
     ```powershell
     python scripts/train_models.py
     ```

6. **Start the API Server**
   - Start FastAPI via Uvicorn:
     ```powershell
     uvicorn app.main:app --reload
     ```
   - The API will be available at `http://localhost:8000`.

## Architecture Details
- **FastAPI:** Core framework providing async routes and dependency injection.
- **SQLAlchemy & Alembic:** Data modeling and migrations.
- **JWT Auth:** Bearer token authentication via OAuth2 standard.
- **Scikit-Learn:** Used for training demand forecasting models.

**Note:** If the frontend fails to log in, ensure MySQL is running, the migrations are applied, and `seed_demo.py` ran successfully.
